🎓 Student Record Management System

> A full-featured command-line application to manage student records with complete CRUD operations, search functionality, and persistent SQLite storage.
---
✨ Features
➕ Add new student records
📋 View all students in formatted table
✏️ Update existing student information
🗑️ Delete student records by ID
🔍 Search students by name or ID
💾 Persistent storage using SQLite
---
🛠️ Tech Stack
Technology	Purpose
Python	Core application logic
SQLite	Local database storage
CRUD Operations	Full data management
---
🚀 Getting Started
Prerequisites
Python 3.x installed
Installation
```bash
# Clone the repository
git clone https://github.com/Hetvi-pipaliya/student-record-system.git

# Navigate to project directory
cd student-record-system

# Run the application
python main.py
```
---
📸 Usage
```
===== Student Record System =====
1. Add Student
2. View All Students
3. Update Student
4. Delete Student
5. Search Student
6. Exit
```
